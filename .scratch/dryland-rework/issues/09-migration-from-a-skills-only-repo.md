# Migration from a skills-only repo

Type: grilling
Blocked by: 08

## Question

Decide how a repo with .scratch tickets and maps written by the upstream skills moves into the state store: what is imported, what happens to the old files, how forge links and claims carry over, and whether migration is re-runnable. Baseline: the storage decision (event log on a git ref) and the one-way-migration positioning in the map Notes.
